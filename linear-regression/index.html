Pseudocode  伪代码

  1. Initialize w, c randomly (x̄-centered model: ŷ = w·(x−x̄) + c)  随机初始化
  2. repeat until convergence:  重复直到收敛
  3. ŷᵢ = w·(xᵢ−x̄) + c; eᵢ = ŷᵢ − yᵢ  计算预测值与残差
  4. ∂L/∂w = (2/n)Σeᵢ·(xᵢ−x̄); ∂L/∂c = (2/n)Σeᵢ  计算梯度
  5. w ← w − lr·∂L/∂w; c ← c − lr·∂L/∂c  更新参数
  6. return w, b = c − w·x̄ (standard form)  返回标准形式参数

Evaluation Metrics Reference  评估指标详解

All metrics shown in the visualisation above — full names, formulas, and interpretation.

MSE Mean Squared Error
均方误差
含义：每个预测值与真实值之差的平方，对 n 个样本取均值。平方操作使大误差受到更重的惩罚，并保证损失恒为非负。

直觉：把每条残差线的长度平方后求平均。残差越长（预测偏差越大），MSE 越高。梯度下降的目标就是最小化 MSE。

局限：MSE 的单位是目标变量单位的平方（如房价平方）。直观解释时通常取平方根得到 RMSE。MSE 对异常值敏感，因为异常点的误差被平方放大。
范围：[0, +∞)，越小越好
RMSE Root Mean Squared Error
均方根误差
含义：MSE 的平方根。与目标变量同量纲，可以直接解释为"平均预测误差的典型大小"。

直觉：如果 RMSE = 1.2，大致意味着模型的典型预测误差约为 ±1.2（原始单位）。

与 MSE 的关系：最小化 MSE 等价于最小化 RMSE，因此梯度下降只需针对 MSE 进行。RMSE 仅用于最终报告，帮助人类理解误差大小。
范围：[0, +∞)，越小越好
R² Coefficient of Determination
决定系数
含义：模型解释的方差比例。SS_res 是残差平方和（预测误差），SS_tot 是总方差（用均值预测的误差）。R²=1 说明完美拟合，R²=0 说明模型和直接用均值一样差。

直觉：R² = 0.85 意味着模型解释了目标变量 85% 的变化，剩余 15% 是模型未能捕捉的噪声或非线性成分。

注意：R² 可以为负（当模型比均值预测更差时）。R² 高不代表因果关系，也不代表模型对新数据有好的泛化能力。
范围：(-∞, 1]，越接近 1 越好
∂L/∂w, ∂L/∂b Gradient of Loss
损失对参数的梯度
含义：梯度指明了 MSE 随参数 w 或 b 增大时的变化速率和方向。梯度为正 → 参数增大会增加损失 → 应减小参数。梯度为负 → 应增大参数。

几何意义：梯度是损失曲面在当前参数处的"上坡"方向。梯度下降沿负梯度方向移动，即向"下坡"走，找到局部（对线性回归即全局）最小值。

本可视化使用 x̄ 中心化特征：ŷ = w·(xᵢ−x̄) + c，这使得 Hessian 矩阵近似对角，条件数降低，梯度下降在 w 和 c 方向上步长均衡，收敛更快。
符号决定更新方向，量级影响步长
lr (α) Learning Rate
学习率
含义：每次梯度下降更新的步长大小。控制参数沿梯度反方向移动多远。本例 lr = 0.06。

过大：参数更新幅度太大，可能越过最小值，导致损失震荡甚至发散（梯度爆炸）。
过小：收敛极慢，需要大量迭代才能到达最优值。

稳定性条件：对于 MSE 损失，lr 需满足 lr < 2 / λ_max，其中 λ_max 是 Hessian 最大特征值。

自适应方法：实践中常用 Adam、RMSProp 等方法，它们对每个参数自动调整有效学习率，对特征尺度不敏感。
本例：lr = 0.06（x̄ 中心化后的稳定值）

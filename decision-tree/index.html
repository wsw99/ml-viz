Decision Tree Concepts Reference  决策树核心概念详解

Gini impurity, splitting criterion, depth control, and decision boundaries — all concepts shown in the visualisation above.

Gini ImpurityNode Impurity Measure
节点不纯度
含义：衡量节点中类别的混杂程度。Gini=0 表示节点纯净（全是一个类别）；Gini=0.5 表示最混杂（二分类各占50%）。

直觉：随机从节点中取两个样本，它们属于不同类别的概率。Gini = P(类别不同) = 1 − Σpₖ²。

可视化：柱状图显示每个访问节点的 Gini 值。从根节点（≈0.5，混杂）到叶节点（≈0，纯净），Gini 逐步下降。
范围：[0, 0.5]（二分类），越小越好
ΔGiniGini Gain / Impurity Reduction
Gini 增益 / 不纯度下降
含义：对每个候选分裂（特征 + 阈值），计算分裂后加权平均 Gini 比父节点下降了多少。CART 每步选择 ΔGini 最大的分裂。

权重：子节点按样本量加权——大子节点的 Gini 权重更高，防止偏向产生极小但纯净子节点的无意义分裂。

可视化："Split feat + Threshold + ΔGini" 参数在 split 步骤中显示，黄色虚线为待应用的候选分裂边界。
范围：[0, 0.5]，越大越好
CARTClassification and Regression Trees
分类回归树算法
算法流程：从根节点开始，对每个节点：① 若满足终止条件（纯净或达到最大深度）→ 创建叶节点，预测多数类；② 否则遍历所有特征和候选阈值，选 ΔGini 最大的分裂，将数据划入左右子节点，递归。

二元分裂：CART 每次只做二叉分裂（左：feat ≤ t，右：feat > t），生成完全二叉树。

本例：max_depth=2，XOR 数据，最优分裂序列：x1≤~5 → x2≤~5（左右各一次），形成 4 个矩形区域。
叶节点数：≤ 2ᵈ（d=最大深度）
Depth & OverfittingModel Complexity Control
深度与过拟合
深度与复杂度：每增加一层深度，叶节点数量最多翻倍。深度越大，模型越复杂，越容易过拟合训练数据（在训练集上完美但在测试集上表现差）。

欠拟合 vs 过拟合：depth=1（单一分裂）通常欠拟合；depth=n（每个样本一个叶节点）完全过拟合。

剪枝：限制 max_depth 是最简单的正则化方式。其他方法包括最小叶节点样本数、代价复杂度剪枝（cost-complexity pruning）等。
本例：max_depth = 2
Decision BoundaryAxis-Aligned Piecewise Boundary
轴对齐分段决策边界
特点：决策树的边界始终平行于特征轴（水平或垂直线段），将特征空间划分为矩形区域。与逻辑回归的线性边界不同，决策树可以学习任意复杂的非线性边界（通过增加深度）。

非线性优势：本例数据对逻辑回归线性不可分（4 个簇无法用一条直线完美分开），但深度为 2 的决策树即可完美分类。

可视化：紫色实线 = 已应用的分裂边界；黄色虚线 = 待应用的候选分裂；蓝/红背景 = 最终预测区域。
本例：4 个矩形叶区域

  1. for t = 1 to n_trees:  对每棵树

  4. OOB_t ← D ∖ S_t  袋外样本（未被选中的点）
  5. def predict(x):  预测新样本
  6. votes ← [T_t(x) for t]  每棵树各自预测
  7. return majority_vote(votes)  多数票决定最终预测
  8. OOB_err ← avg error on OOB sets  袋外误差 = 免费验证集

Random Forest Concepts Reference  随机森林核心概念详解

Bootstrap sampling, out-of-bag error, majority voting, and feature importance — all concepts shown in the visualisation above.

BootstrapBootstrap Sampling
Bootstrap 采样
含义：从 n 个训练点中有放回地抽取 n 次，得到一个大小为 n 的子集 S_t。每次抽取时，每个点被选中的概率均为 1/n。

期望覆盖率：任意一个点被选中至少一次的概率 ≈ 1 − e⁻¹ ≈ 63.2%。剩余 ~36.8% 的点未被选中，称为袋外（OOB）样本。

多样性：每棵树看到不同的子集 → 不同的 CART 分裂 → 不同的决策边界。多样性是集成有效的关键。
平均唯一样本：~63%（1/e 规则）
OOB ErrorOut-of-Bag Error
袋外误差
含义：对每个训练点 xᵢ，只用那些 xᵢ 没有出现在其 bootstrap 样本中的树来预测 xᵢ，然后统计这些"免费"预测的误差率。

优势：无需划分验证集——每棵树的 OOB 样本天然充当验证集。OOB 误差是泛化误差的良好无偏估计，且计算代价极低。

集成 OOB：在所有树训练完毕后，对每个点用其 OOB 树进行多数投票，得到集成 OOB 误差（比单树 OOB 误差更低）。
范围：[0, 1]，越小越好
Majority VoteMajority Vote Aggregation
多数投票聚合
含义：对新样本 x，让每棵树 T_t 独立预测类别，最终取得票最多的类别作为集成预测结果。

为什么有效：假设每棵树的错误率 ε < 0.5 且树之间相互独立，则当树的数量增加时，集成错误率 → 0（由二项分布尾概率决定）。实际中树不完全独立，但多样性仍能大幅降低方差。

可视化：★ 号查询点周围的 T1/T2/T3 彩色圆点 = 每棵树的投票（蓝=1，红=0）。
奇数棵树时：不会平票（推荐）
Feature ImportanceMean Decrease in Impurity
特征重要性（平均不纯度下降）
含义：对每个特征 f，统计其在所有树的所有节点中引起的 Gini 不纯度加权下降之和，再按树数平均。

权重：节点的 Gini 增益按该节点样本量 n_v/n 加权——处理大量样本的节点贡献更大。

本例：XOR 数据天生要求 x1 和 x2 同等重要（第一层用其中一个，第二层用另一个），因此两个特征的重要性应接近 50/50。
归一化后：各特征之和 = 1
AccuracyClassification Accuracy
分类准确率
含义：正确分类的样本占总样本的比例。对于集成模型，OOB 准确率 = 1 − OOB 误差，是不需要单独验证集的泛化误差估计。

与单棵树的比较：随机森林通过降低方差（多棵树平均）来提高准确率，但偏差与单棵树相似。在大多数实际数据集上，随机森林的 OOB 准确率远高于任意单棵树的 OOB 准确率。

局限：Accuracy 对类别不平衡数据有误导性，此时应关注 Precision/Recall/F1/AUC-ROC（见逻辑回归页面）。
范围：[0, 1]，越大越好

Pseudocode  伪代码

  1. Initialize w₁, w₂, b randomly  随机初始化参数
  2. repeat until convergence:  重复直到收敛
  3. ŷᵢ = σ(w₁x₁ᵢ + w₂x₂ᵢ + b)  计算预测概率
  4. ∂L/∂wₖ = (1/n)Σ(ŷᵢ−yᵢ)xₖᵢ; ∂L/∂b = (1/n)Σ(ŷᵢ−yᵢ)  计算梯度
  5. w₁,w₂,b ← w₁,w₂,b − lr · ∇L  更新参数
  6. return w₁, w₂, b  返回最终参数

Evaluation Metrics Reference  评估指标详解

All metrics shown in the visualisation above — full names, formulas, and interpretation.

Log LossBinary Cross-Entropy Loss
二元交叉熵损失
含义：对每个样本，惩罚"高置信度但预测错误"的情况。如果模型以概率 0.99 预测 y=1，但实际 y=0，则损失 = -log(0.01) ≈ 4.6，极大。

直觉：最大似然估计的负对数。最小化 Log Loss 等价于找最可能生成当前训练数据的参数。

梯度下降：∂L/∂w = (1/n)Σ(ŷᵢ−yᵢ)xᵢ，与线性回归的 MSE 梯度形式完全相同——这是 Sigmoid + 交叉熵的优雅配合。
范围：[0, +∞)，越小越好
σ(z)Sigmoid Function
Sigmoid 函数
含义：将任意实数 z 压缩到 (0, 1)，输出解释为"属于正类的概率"。z → +∞ 时 σ → 1，z → −∞ 时 σ → 0，z=0 时 σ=0.5。

决策边界：σ(z) = 0.5 当 z = 0，即 w₁x₁ + w₂x₂ + b = 0。这条直线就是可视化中的紫色边界线。

可视化中的高亮点：每步高亮的是最靠近边界的点（|σ(z)−0.5| 最小），这是模型最"不确定"的样本。
范围：(0, 1)
AccuracyClassification Accuracy
准确率
含义：正确分类的样本占总样本的比例。TP=真阳性，TN=真阴性，FP=假阳性，FN=假阴性。

局限：类别不平衡时（如 95% 负样本），全部预测为负类也能达到 95% 准确率，但模型毫无意义。这时需要 Precision / Recall / F1。
范围：[0, 1]，越接近 1 越好
Precision / Recall / F1Classification Quality Metrics
精确率 / 召回率 / F1 分数
Precision（精确率）：预测为正类中真正是正类的比例。高 Precision → 少误报（FP 少）。
Recall（召回率）：所有正类样本中被正确找到的比例。高 Recall → 少漏报（FN 少）。

Precision-Recall 权衡：降低分类阈值 → Recall ↑ 但 Precision ↓；提高阈值 → Precision ↑ 但 Recall ↓。

F1：Precision 和 Recall 的调和平均，是两者的综合衡量，适合类别不平衡时作为主指标。
三者范围均：[0, 1]，越接近 1 越好
Decision BoundaryLinear Decision Boundary
线性决策边界
含义：将特征空间划分为正类区域和负类区域的直线（2D）/ 超平面（多维）。边界的一侧 σ(z) > 0.5（预测正类），另一侧 σ(z) < 0.5（预测负类）。

可视化：最终步骤中，背景颜色表示模型对每个区域的预测类别——蓝色 = 正类，红色 = 负类。✓ 表示正确分类，✗ 表示错误分类。

局限：逻辑回归只能学习线性边界。若数据线性不可分（如 XOR 问题），需要特征工程或神经网络。
本例：lr = 0.2（x̄ 中心化特征）
